# Sanbuilder GameKit

This repository is an optional H5 mobile game capability pack for the connected Sanbuilder core. It does not replace the core coordinator or create a second design authority.

Before game design work:

1. Resolve the brand, game product, adapter, environment, taste, memory, contracts, and production repository through the connected Design Harness.
2. Read `skills/h5-game-design/SKILL.md` and `config/capability-pack.yml`.
3. Keep all product writes behind the core digest-bound proposal approval and implementation grant.
4. Treat playable mockups as evidence, not shipped product truth.
5. Run product-native tests plus the H5 QA contract before proposing a draft PR.

Never copy the core Harness into this repository. Never store MCP credentials here. Never silently promote an agent preference, playtest observation, or rejected concept into durable brand or product memory.
